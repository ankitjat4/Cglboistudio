📲 Install as Native WebAPK (Android / Pad / iOS)

1. Hosting on GitHub Pages (Free Forever):
Push all repository files (index.html, style.css, app.js, manifest.json, sw.js, .nojekyll, and the .png / .svg icons) to a GitHub repo. Go to Settings ➔ Pages ➔ Branch: main / root and Save.
2. Installing as a Signed Android WebAPK (Phone & OnePlus Pad):
Open your GitHub Pages URL (https://<username>.github.io/<repo>/) in Google Chrome.
• Tap the 📲 Install App button in the Dashboard header, OR
• Tap Chrome's ⋮ (3-dots menu) ➔ Install app / Add to Home screen ➔ Install.
Chrome will compile and install a true standalone WebAPK into your Android app drawer with 100% offline support!
3. Installing on iPad / iPhone (Safari):
Open the URL in Safari ➔ Tap the Share button ➔ Add to Home Screen.
